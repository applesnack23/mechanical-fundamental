# 2D CAD 학습을 위한 태극기

이번 챕터에서는 2D CAD 설계의 가장 기본적인 기능을 학습합니다.

3D 모델링과 마찬가지로 2D CAD 역시 처음부터 모든 기능을 외울 필요는 없습니다.

실제 작업에서 자주 사용하는 몇 가지 핵심 기능을 반복적으로 사용하면서 자연스럽게 익히는 것이 중요합니다.

이번 챕터에서는 nanoCAD를 이용하여 기본적인 도형을 그리고 수정하는 방법을 학습한 뒤, 최종적으로 태극기를 직접 그려 보겠습니다.

---

#### nanoCAD 준비

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image.png)

이번 과정에서는 nanoCAD v5를 사용합니다.

[https://nanocad.com/products/nanocad-free/](https://nanocad.com/products/nanocad-free/)

nanoCAD는 AutoCAD와 매우 유사한 방식으로 사용할 수 있는 2D CAD 프로그램입니다.

이번 과정에서는 기본적인 2D CAD 명령어와 작업 방식을 익히는 용도로 사용합니다.

설치가 완료되면 nanoCAD를 실행합니다.

초기 화면에서는 `Get Started`를 선택하여 작업 화면으로 진입합니다.

특별한 설정 없이도 바로 사용할 수 있지만 작업 속도를 높이기 위해 몇 가지 기본 설정을 먼저 변경합니다.

---

#### CAD에서 버전보다 중요한 것

CAD 프로그램은 버전에 따라 새로운 기능이 추가되고 인터페이스가 조금씩 달라질 수 있습니다.

하지만 2D 설계에서 사용하는 기본적인 기능은 크게 달라지지 않습니다.

예를 들어 다음과 같은 명령은 오랫동안 CAD의 기본 기능으로 사용되어 왔습니다.

- Line
- Circle
- Trim
- Copy
- Move
- Rotate
- Mirror
- Dimension

따라서 처음 CAD를 배울 때는 최신 버전의 모든 기능을 배우려고 하기보다 기본 명령을 빠르고 정확하게 사용할 수 있도록 연습하는 것이 더 중요합니다.

> CAD 실력은 기능을 얼마나 많이 알고 있는가보다 필요한 기본 기능을 얼마나 빠르고 정확하게 사용할 수 있는가에 더 가깝습니다.
>

먼저 명령창에 다음 명령어를 입력합니다.

#### Right Button Usage

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%201.png)

이렇게 설정하면 작업 상황에 따라 우클릭을 Enter 또는 이전 명령 반복 기능으로 사용할 수 있습니다.

#### 왜 우클릭을 사용하는가

CAD 작업은 대부분 양손을 동시에 사용합니다.

왼손은 다음과 같은 역할을 합니다.

- 명령어 입력
- 숫자 입력
- 단축키 입력

오른손은 마우스를 이용합니다.

- 위치 선택
- 객체 선택
- 화면 이동
- 확대 및 축소

이때 Enter 키를 누르기 위해 손의 위치를 계속 이동하면 작업 흐름이 끊길 수 있습니다.

따라서 오른손의 마우스 우클릭을 Enter 역할로 사용하면 다음과 같은 작업이 가능합니다.

명령어 입력

↓

마우스 조작

↓

우클릭

↓

다음 명령

작은 차이처럼 보이지만 CAD를 오랜 시간 사용하면 작업 속도에 상당한 차이가 생깁니다.

---

#### 마우스 기본 조작

nanoCAD에서 기본적으로 사용하는 마우스 동작은 다음과 같습니다.

| 동작 | 기능 |
| --- | --- |
| 좌클릭 | 객체 또는 위치 선택 |
| 우클릭 | Enter 또는 이전 명령 반복 |
| 휠 클릭 후 이동 | 화면 이동(Pan) |
| 휠 스크롤 | 확대 / 축소 |

2D CAD에서는 화면을 계속 확대하고 이동하면서 작업하기 때문에 마우스 휠 사용에 익숙해지는 것이 중요합니다.

#### Line

가장 먼저 사용할 명령은 Line입니다.

Line은 선을 그리는 가장 기본적인 명령입니다.

명령어는 다음과 같습니다.

`LINE`

또는 단축 명령어를 사용합니다.

`L`

명령을 입력한 뒤 Enter 또는 마우스 우클릭을 합니다.

그다음 첫 번째 점을 선택하고 두 번째 점을 선택하면 선이 만들어집니다.

기본적인 순서는 다음과 같습니다.

1. `L` 입력
2. 우클릭 또는 Enter
3. 시작점 선택
4. 끝점 선택
5. 계속해서 다음 점 선택
6. 작업 종료

마우스로 위치를 선택할 수도 있고 필요한 경우 숫자를 입력하여 정확한 길이를 지정할 수도 있습니다.

---

#### 객체 선택

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%202.png)

CAD에서는 객체를 선택하는 방법도 중요합니다.

마우스를 드래그하는 방향에 따라 선택 방식이 달라집니다.

**왼쪽에서 오른쪽으로 선택**

선택 영역 안에 완전히 포함된 객체만 선택됩니다.

**오른쪽에서 왼쪽으로 선택**

선택 영역 안에 들어오거나 경계와 교차하는 객체도 함께 선택됩니다.

따라서 작은 부분을 빠르게 선택할 때는 오른쪽에서 왼쪽으로 드래그하는 방법이 편리한 경우가 많습니다.

두 방식의 차이는 이후 객체가 많아질수록 매우 중요해집니다.

---

#### Erase

잘못 그린 객체를 삭제할 때는 Erase 명령을 사용합니다.

명령어는 다음과 같습니다.

`ERASE`

단축 명령어는 다음과 같습니다.

`E`

기본적인 사용 순서는 다음과 같습니다.

1. 삭제할 객체 선택
2. `E` 입력
3. 우클릭 또는 Enter

또는 명령을 먼저 실행한 뒤 삭제할 객체를 선택하는 방식으로 사용할 수도 있습니다.

처음에는 여러 개의 선을 자유롭게 그리고 일부 선을 선택하여 삭제하는 연습을 반복해 봅니다.

---

#### 객체 스냅

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%203.png)

CAD에서 정밀한 설계를 하기 위해 반드시 알아야 하는 기능 중 하나가 객체 스냅(Object Snap)입니다.

단축키는 다음과 같습니다.

`F3`

객체 스냅을 활성화하면 기존 객체의 특정 위치를 정확하게 선택할 수 있습니다.

대표적으로 다음 위치를 찾을 수 있습니다.

- 끝점
- 중점
- 중심점
- 교차점

예를 들어 두 선을 정확하게 연결해야 한다면 눈으로 위치를 맞추는 것이 아니라 기존 선의 끝점에 스냅하여 연결합니다.

마우스를 기존 객체 주변으로 이동하면 스냅 가능한 위치에 표시가 나타납니다.

> 정밀한 CAD 작업에서는 눈으로 맞추는 것이 아니라 스냅을 이용하여 정확한 위치를 선택해야 합니다.
>

#### 직교 모드

수평선과 수직선을 정확하게 그릴 때 사용하는 기능이 직교 모드(Ortho Mode)입니다.

단축키는 다음과 같습니다.

`F8`

직교 모드를 활성화하면 마우스 이동 방향이 기본적으로 다음 방향으로 제한됩니다.

- 0°
- 90°
- 180°
- 270°

따라서 수평선이나 수직선을 그릴 때 매우 편리합니다.

예를 들어 Line 명령을 실행한 뒤 F8을 켜고 마우스를 이동해 보면 수평 또는 수직 방향으로만 움직이는 것을 확인할 수 있습니다.

---

#### Rectangle

사각형을 만들 때는 Rectangle 명령을 사용할 수 있습니다.

명령어는 다음과 같습니다.

`RECTANGLE`

대표적인 단축 명령어는 다음과 같습니다.

`REC`

기본 사용 방법은 다음과 같습니다.

1. `REC` 입력
2. 첫 번째 모서리 선택
3. 반대쪽 모서리 선택

이렇게 하면 하나의 사각형이 만들어집니다.

하지만 이번 태극기 연습에서는 Rectangle만 사용하기보다 Line을 이용해 사각형을 직접 만들어 보는 것을 추천합니다.

Line과 Snap 사용에 익숙해지는 것이 목적이기 때문입니다.

---

#### Circle

원을 그릴 때는 Circle 명령을 사용합니다.

명령어는 다음과 같습니다.

`CIRCLE`

단축 명령어는 다음과 같습니다.

`C`

원을 만드는 방법은 여러 가지가 있습니다.

이번 과정에서는 가장 기본적인 두 가지를 사용합니다.

---

#### 중심점과 반지름으로 원 만들기

가장 일반적인 방법입니다.

1. `C` 입력
2. 중심점 선택
3. 반지름 입력

예를 들어 반지름 50 mm의 원을 만들고 싶다면 중심점을 선택한 뒤 `50`을 입력합니다.

---

#### 두 점으로 원 만들기

원 지름의 양 끝점을 알고 있는 경우에는 2P 방식을 사용할 수 있습니다.

1. `C` 입력
2. `2P` 입력
3. 첫 번째 점 선택
4. 두 번째 점 선택

두 점 사이의 거리가 원의 지름이 됩니다.

태극 문양을 만들 때 매우 편리하게 사용할 수 있습니다.

#### 대각선 만들기

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%206.png)

이때 객체 스냅 F3을 사용합니다.

오른쪽 위 → 왼쪽 아래

두 선이 만나는 교차점이 태극기의 정확한 중심이 됩니다.

#### 중심 원 만들기

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%206.png)

태극 문양의 기본 외곽이 되는 원입니다.

이 과정에서 CAD에서 보조선을 이용하여 중심을 찾는 방법도 함께 익힐 수 있습니다.

#### 태극 문양 만들기

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%207.png)

태극 내부의 곡선은 Circle의 2P 기능을 이용하여 만들 수 있습니다.

기존 원과 중심선을 기준으로 필요한 위치를 선택하여 내부 원을 만듭니다.

이 단계에서는 필요 이상의 선과 원이 만들어질 수 있습니다.

불필요한 부분은 뒤에서 배울 Trim 기능을 이용하여 제거합니다.

#### Trim

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%208.png)

Trim은 서로 교차하는 객체의 불필요한 부분을 잘라낼 때 사용하는 명령입니다.

명령어는 다음과 같습니다.

`TRIM`

단축 명령어는 다음과 같습니다.

`TR`

기본적인 작업은 다음과 같습니다.

1. `TR` 입력
2. 필요한 기준 객체 선택 (완료되면 우큭릭)
3. 잘라낼 부분 선택

버전이나 설정에 따라 객체 선택 과정은 조금 달라질 수 있지만 핵심 개념은 동일합니다.

> 다른 선과 만나는 지점을 기준으로 불필요한 부분을 잘라냅니다.
> 

태극 문양을 만드는 과정에서 원의 불필요한 부분을 제거할 때 사용합니다.

#### 보조선 제거

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%209.png)

태극 문양을 만들기 위해 사용했던 대각선은 최종 도면에서는 필요하지 않습니다.

객체를 선택하고 Erase 명령을 이용하여 삭제합니다.

`E`

보조선을 만들고 필요한 작업이 끝난 뒤 제거하는 방식은 CAD 작업에서 자주 사용됩니다.

#### Copy

같은 형상을 여러 번 만들어야 할 때는 다시 그리지 않고 Copy를 사용합니다.

명령어는 다음과 같습니다.

`COPY`

단축 명령어는 다음과 같습니다.

`CO`

기본적인 사용 방법은 다음과 같습니다.

1. 복사할 객체 선택
2. `CO` 입력
3. 기준점 선택
4. 복사할 위치 선택

필요한 경우 거리 값을 직접 입력할 수도 있습니다.

태극기의 괘를 만드는 과정에서는 하나의 선이나 사각형을 만든 뒤 Copy를 이용해 반복적으로 배치할 수 있습니다.

예를 들어 10, 11, 21, 22 mm와 같이 필요한 간격을 숫자로 지정하여 정확하게 복사할 수 있습니다.

---

#### Rotate

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%2010.png)

객체를 회전할 때는 Rotate 명령을 사용합니다.

명령어는 다음과 같습니다.

`ROTATE`

단축 명령어는 다음과 같습니다.

`RO`

기본적인 순서는 다음과 같습니다.

1. 회전할 객체 선택
2. `RO` 입력
3. 회전 기준점 선택
4. 회전 각도 지정

태극기의 괘는 사각형의 각 방향에 배치되기 때문에 Rotate를 이용하면 동일한 형상을 필요한 각도로 쉽게 회전할 수 있습니다.

#### Move

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%2011.png)

객체를 다른 위치로 이동할 때는 Move 명령을 사용합니다.

명령어는 다음과 같습니다.

`MOVE`

단축 명령어는 다음과 같습니다.

`M`

기본적인 사용 방법은 다음과 같습니다.

1. 이동할 객체 선택
2. `M` 입력
3. 기준점 선택
4. 이동할 위치 선택

CAD에서 Move는 매우 자주 사용하는 기능 중 하나입니다.

객체를 눈대중으로 끌어 이동하기보다 기준점과 스냅을 활용하여 정확하게 이동하는 습관을 들이는 것이 좋습니다.

---

#### Mirror

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%2012.png)

대칭 형상을 만들 때는 Mirror 명령을 사용합니다.

명령어는 다음과 같습니다.

`MIRROR`

단축 명령어는 다음과 같습니다.

`MI`

기본적인 사용 순서는 다음과 같습니다.

1. 대칭할 객체 선택
2. `MI` 입력
3. 대칭 기준선의 첫 번째 점 선택
4. 대칭 기준선의 두 번째 점 선택
5. 원본 객체 삭제 여부 선택

원본을 유지하면서 대칭 복사하려면 일반적으로 원본 삭제 여부에서 `N`을 선택합니다.

태극기처럼 좌우 또는 상하 대칭을 많이 사용하는 형상에서 매우 유용합니다.

---

#### 반복되는 형상은 다시 그리지 않는다

CAD에서 작업 속도를 높이는 중요한 원칙 중 하나는 같은 형상을 계속 새로 그리지 않는 것입니다.

이미 정확하게 만들어진 형상이 있다면 다음 기능을 활용합니다.

- Copy
- Rotate
- Mirror
- Array

예를 들어 태극기의 괘 하나를 정확하게 만든 뒤 복사하고 회전하고 대칭시키면 나머지 형상을 훨씬 빠르게 만들 수 있습니다.

이러한 작업 방식이 익숙해질수록 설계 속도가 크게 향상됩니다.

---

#### Dimension

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%2013.png)

도면에 치수를 표시할 때는 Dimension 기능을 사용합니다.

명령어는 다음과 같습니다.

`DIMENSION`

단축 명령어는 다음과 같습니다.

`DIM`

환경에 따라 다양한 치수 명령을 사용할 수 있습니다.

기본적으로 다음 과정을 통해 치수를 표시합니다.

1. 치수의 시작 위치 선택
2. 끝 위치 선택
3. 치수를 표시할 위치 선택

치수가 생성되면 실제 거리 또는 크기가 도면에 표시됩니다.

기계 제작 도면에서는 이 치수가 제작자가 부품의 크기를 이해하는 중요한 정보가 됩니다.

---

#### 치수 스타일

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%2014.png)

치수를 표시했을 때 글씨나 화살표가 너무 크거나 작다면 치수 스타일(Dimension Style)을 수정합니다.

명령어는 다음과 같습니다.

`DIMSTYLE`

Dimension Style Manager에서 사용할 스타일을 선택한 뒤 Modify를 선택합니다.

대표적으로 다음 항목을 변경할 수 있습니다.

**Symbols and Arrows**

- Arrow Size

치수선 끝에 표시되는 화살표의 크기를 변경합니다.

**Text**

- Text Height

치수 문자의 높이를 변경합니다.

도면의 전체 크기에 맞게 적절한 크기로 설정합니다.

#### Inspector

![image.png](2D%20CAD%20%ED%95%99%EC%8A%B5%EC%9D%84%20%EC%9C%84%ED%95%9C%20%ED%83%9C%EA%B7%B9%EA%B8%B0/image%2015.png)

이미 생성된 객체나 치수의 세부 정보를 확인하고 수정할 때 Inspector를 사용할 수 있습니다.

예를 들어 치수 객체를 선택하면 Inspector에서 해당 객체의 여러 속성을 확인할 수 있습니다.

필요한 값을 수정하면 도면에도 변경 사항이 반영됩니다.

이러한 속성 수정 기능은 이후 도면이 복잡해졌을 때 많이 사용하게 됩니다.

지금까지 배운 기능을 조합하면 태극기를 완성할 수 있습니다.

#### CAD에서 중요한 것은 반복

처음에는 명령어를 하나씩 생각하면서 입력하기 때문에 작업이 느릴 수 있습니다.

하지만 동일한 명령을 반복해서 사용하면 점차 단축 명령을 생각하지 않고도 자연스럽게 사용할 수 있게 됩니다.

예를 들어 다음과 같은 명령은 손에 익을 정도로 반복하는 것이 좋습니다.

`L` → Line

`E` → Erase

`TR` → Trim

`CO` → Copy

`M` → Move

`RO` → Rotate

`MI` → Mirror

그리고 정밀 작업을 위해 다음 단축키도 자연스럽게 사용할 수 있어야 합니다.

`F3` → Object Snap

`F8` → Ortho Mode

CAD 역시 단순한 지식이라기보다 반복을 통해 익숙해지는 기술에 가깝습니다.
