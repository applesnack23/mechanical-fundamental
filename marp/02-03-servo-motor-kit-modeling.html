발표자 노트 · 원문 # 서보모터 연습키트 3D모델링 지난 챕터에서는 Fusion 360의 가장 기본적인 기능을 살펴보았습니다. 핵심적인 모델링 흐름을 정리하면 다음과 같습니다. 1. 2D 스케치를 만든다. 2. 돌출(Extrude)을 이용해 3D 형상을 만든다. 3. 여러 부품을 접합하여 조립 구조를 만든다. 이번 챕터에서는 여기에서 한 단계 더 나아가 실제 자동화 장비 설계에 가까운 형태의 모델링을 진행합니다. 이번 실습의 목표는 다음과 같습니다. 1. 조금 더 복잡한 2D 스케치를 작성한다. 2. 스케치를 기반으로 필요한 3D 부품을 만든다. 3. 여러 기성품과 직접 만든 부품을 조합한다. 4. 하나의 장비 형태로 완성한다. 이번에도 새로운 고급 기능을 많이 사용하는 것이 목적은 아닙니다. 지금까지 배운 기본 기능을 반복하여 실제 장비와 비슷한 구조를 만드는 것이 핵심입니다.

발표자 노트 · 원문 #### STEP 파일 STEP 또는 STP 파일은 서로 다른 CAD 프로그램 사이에서 3D 모델 데이터를 교환하기 위해 사용하는 표준 형식입니다. STEP은 ISO 10303 표준을 기반으로 합니다. Fusion에서 작성한 모델뿐만 아니라 다른 CAD 프로그램으로 제작된 모델도 STEP 형식으로 제공받으면 불러와 사용할 수 있습니다. 따라서 실제 설계에서는 제조사에서 제공하는 STEP 파일을 다운로드하여 장비 설계에 활용하는 경우가 많습니다. 예를 들어 모터를 직접 모델링할 필요 없이 제조사에서 제공하는 모터의 STEP 파일을 다운로드하고, 실제 설계에서는 모터를 고정할 브라켓이나 구조물만 직접 설계할 수 있습니다.

발표자 노트 · 원문 #### 전체 제어 구조 이번 키트의 제어 구조를 매우 단순하게 표현하면 다음과 같습니다. 1. PLC에 제어 프로그램을 작성한다. 2. PLC가 모터 제어에 필요한 명령을 전달한다. 3. 모터 드라이브가 명령을 받아 모터를 구동한다. 4. 모터가 회전한다. 5. 볼스크류를 통해 회전 운동이 직선 운동으로 변환된다. 구체적인 전기 배선과 PLC 프로그램은 이후 전기 및 PLC 과정에서 학습합니다. 이번 챕터에서는 각 부품이 어떤 위치에 배치되고 어떻게 기계적으로 연결되는지만 살펴봅니다.

발표자 노트 · 원문 #### 디자인 유형 설정 이번 프로젝트에서는 여러 기성품과 직접 제작할 부품을 하나의 파일 안에서 관리하기 위해 하이브리드 디자인을 사용합니다. 브라우저에서 디자인 유형을 확인하고 하이브리드 방식으로 변경합니다. 이제 준비한 기성품들을 작업 공간에 하나씩 배치합니다.

발표자 노트 · 원문 #### 직교 로봇 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-006.png) 먼저 KMR45-S10-N300-L10 모델을 작업 공간으로 가져옵니다. 초기 배치 위치는 크게 중요하지 않습니다. 이후 이동과 정렬 기능을 이용해 원하는 위치로 수정할 수 있기 때문입니다. 다만 가져온 모델을 사용할 때는 두 가지를 확인합니다.

발표자 노트 · 원문 #### **강체 그룹** ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-007.png) 외부에서 가져온 조립품은 내부에 여러 개의 구성요소를 가지고 있을 수 있습니다. 각 구성요소가 서로 분리되어 움직이지 않도록 필요한 경우 강체 그룹으로 설정합니다. 강체 그룹을 적용하면 내부 부품들이 하나의 조립체처럼 함께 움직입니다. **상위로부터 고정** 삽입한 부품이 상위 구조에 고정되어 있으면 위치를 변경할 수 없습니다. 이후 배치 작업을 위해 움직일 필요가 있다면 상위로부터 고정을 해제합니다. 반대로 위치를 변경할 필요가 없다면 고정된 상태로 사용할 수도 있습니다.

발표자 노트 · 원문 #### 볼스크류와 LM 가이드 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-008.png) 이번에 사용하는 직교 로봇 구조에는 볼스크류와 LM 가이드가 포함되어 있습니다. **볼스크류** 모터의 회전 운동을 직선 운동으로 변환하는 역할을 합니다. 모터가 볼스크류를 회전시키면 볼스크류와 결합된 이동부가 직선 방향으로 이동합니다. **LM 가이드와 LM 블록** 이동부가 움직일 때 원하는 방향으로 정확하게 이동할 수 있도록 안내하고 지지하는 역할을 합니다. 볼스크류가 이동을 만들어 낸다면 LM 가이드는 이동 방향을 안정적으로 유지하는 역할을 한다고 이해하면 좋습니다.

발표자 노트 · 원문 #### 서보모터 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-009.png) 다음으로 서보모터 모델을 작업 공간에 가져옵니다. 처음에는 원하는 위치에 정확히 놓을 필요가 없습니다. 이후 접합 기능을 이용하여 직교 로봇과 연결합니다.

발표자 노트 · 원문 #### 모터와 볼스크류 조립 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-010.png) 모터를 볼스크류와 연결하기 전에 두 부품에서 어떤 부분이 서로 연결되어야 하는지 먼저 확인합니다. 모터에는 회전축이 있고 볼스크류에도 입력축이 있습니다. 실제 장비에서는 두 축을 직접 연결하지 않고 일반적으로 커플링을 사용합니다. 커플링은 다음과 같은 역할을 합니다. - 모터 축과 볼스크류 축 연결 - 회전력 전달 - 미세한 축 정렬 오차 흡수 - 진동 및 충격 완화 실제 설계에서는 축 직경과 허용 토크 등을 고려하여 적절한 커플링을 선정해야 합니다. 이번 모델에서는 커플링 모델링을 생략하고 모터와 볼스크류의 위치 관계를 중심으로 연습합니다.

발표자 노트 · 원문 #### 접합을 이용한 조립 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-011.png) 모터와 볼스크류를 조립하기 위해 다음 기능을 사용합니다. 조립 → 접합 단축키는 `J`입니다. 접합에서는 두 구성요소의 기준점을 선택합니다. 예를 들어 다음과 같이 선택할 수 있습니다. - 구성요소 1 : 모터의 고정 홀 중심 - 구성요소 2 : 볼스크류의 고정 홀 중심 스냅점을 선택할 때는 원의 끝부분이 아니라 중심점이 선택되었는지 확인하는 것이 중요합니다. 두 기준점을 선택하면 두 부품이 서로 결합됩니다. 처음부터 원하는 방향으로 배치되지 않을 수도 있습니다. 이 경우 다음 기능을 사용하여 조정합니다. - 반전 - 각도 - 간격띄우기 부품의 초기 위치와 선택한 스냅점에 따라 필요한 값은 달라질 수 있으므로 화면을 확인하면서 적절히 수정합니다.

발표자 노트 · 원문 #### 모터 드라이브 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-012.png) 다음으로 모터 드라이브 모델을 작업 공간에 배치합니다. 아직 정확한 위치를 결정하지 않고 우선 작업 공간에 가져오는 것만으로 충분합니다. 모터 드라이브는 이후 PLC와 모터 사이의 배선 공간까지 고려하여 배치합니다.

발표자 노트 · 원문 #### PLC 배치 이번 키트에서는 PLC를 하나의 모듈 형태로 구성합니다. PLC는 크게 다음과 같은 부품으로 구성합니다. - Base - Power - CPU - 위치 제어 관련 모듈 - 출력 모듈 - 입력 모듈 각 모듈의 구체적인 기능은 이후 PLC 과정에서 학습합니다. 지금은 각각의 부품을 하나씩 배치하고 조립하여 PLC 전체 구조를 만드는 것이 목적입니다.

발표자 노트 · 원문 #### PLC Base ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-013.png) PLC의 각 모듈은 Base에 장착됩니다. 먼저 XGB-M04A Base를 작업 공간에 배치합니다. 초기 위치는 중요하지 않으므로 별도의 정렬 없이 배치합니다.

발표자 노트 · 원문 #### PLC 전원 모듈 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-014.png) Base를 배치한 뒤 전원 모듈 XGP-DC42를 추가합니다. 아직 전기 기초를 학습하기 전이라면 AC 220V나 DC 24V와 같은 표현이 어렵게 느껴질 수 있습니다. 현재 단계에서는 PLC를 동작시키기 위한 전원 장치가 필요하다는 정도만 이해하면 충분합니다. 이번에는 DC 24V 계통에서 사용하는 전원 모듈을 배치합니다.

발표자 노트 · 원문 #### PLC 모듈 접합 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-015.png) PLC 모듈은 모터와 볼스크류처럼 명확한 원형 중심점이 없는 경우가 많습니다. 따라서 접합할 때 적절한 스냅점을 찾아야 합니다. 조립 결과가 완벽하게 맞지 않는 경우 다음 기능을 이용하여 위치를 조절할 수 있습니다. - 반전 - 각도 - 간격띄우기 이번 실습에서는 제조사 내부의 정확한 체결 구조를 완벽하게 재현하는 것이 목적이 아니므로 외형상 자연스럽게 조립되는 수준으로 진행합니다. 중요한 것은 접합 과정에서 스냅점과 간격띄우기를 사용하는 방법을 익히는 것입니다.

발표자 노트 · 원문 #### PLC CPU 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-016.png) Base와 전원 모듈을 배치한 뒤 CPU를 추가합니다. CPU는 PLC의 프로그램을 실행하고 전체 동작을 처리하는 핵심 장치입니다. 간단하게 PLC의 두뇌 역할을 하는 장치라고 이해할 수 있습니다. 이 역시 접합 기능을 이용하여 기존 PLC 모듈과 연결합니다.

발표자 노트 · 원문 #### 추가 PLC 모듈 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-017.png) 같은 방법으로 준비된 PLC 모듈을 순서대로 추가합니다. 각 모듈의 정확한 전기적 기능은 이후 PLC 과정에서 다루므로 현재는 외형과 배치 방식에 집중합니다. 모든 모듈의 배치가 완료되면 하나의 PLC Set이 만들어집니다.

발표자 노트 · 원문 #### 전체 장비의 구성 기본적인 기성품을 모두 배치하면 이번 키트는 크게 세 개의 모듈로 나눌 수 있습니다. 1. 제어 모듈 : PLC Set 2. 구동 모듈 : 서보모터 + 볼스크류 3. 서보 모터 드라이브 이제 이 세 모듈을 하나의 판넬에 배치해야 합니다.

발표자 노트 · 원문 #### 이동과 정렬 부품의 위치를 조정할 때는 크게 다음 기능을 사용할 수 있습니다. - 이동 - 정렬 - 접합 각 기능의 목적에는 차이가 있습니다. **이동** 구성요소의 위치나 각도를 자유롭게 변경할 때 사용합니다. 이동할 때는 가능하면 객체 선택 대상을 구성요소로 지정합니다. 그래야 본체뿐만 아니라 원점과 스케치 등의 관련 정보도 함께 이동합니다. **정렬** 두 부품의 면이나 방향을 일치시키는 데 사용합니다. 접합과 달리 단순히 위치만 정렬하며 두 부품 사이의 조립 관계가 만들어지는 것은 아닙니다. 정렬에서는 접합의 스냅점이 아니라 면을 기준으로 선택한다는 차이가 있습니다. **접합** 두 부품 사이에 실제 조립 관계를 정의할 때 사용합니다. 따라서 일반적인 작업 흐름은 다음과 같이 사용할 수 있습니다. 이동 ↓ 정렬 ↓ 위치 확인 ↓ 접합

발표자 노트 · 원문 #### 개략적인 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-018.png) 먼저 PLC, 모터 드라이브, 서보모터와 볼스크류의 방향을 맞추고 대략적인 위치를 잡습니다. 이 단계에서는 정확한 치수보다 전체 배치의 균형을 먼저 확인합니다. 일부러 각 장치 사이에 공간을 남겨 두는 것도 중요합니다. 실제 장비에서는 장치 사이로 전원선과 신호선이 지나가기 때문입니다. 따라서 케이블을 정리하기 위한 케이블 덕트 공간도 함께 고려해야 합니다.

발표자 노트 · 원문 #### 케이블 덕트 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-019.png) 제어반이나 자동화 장비에서는 여러 케이블을 정리하기 위해 케이블 덕트를 사용합니다. 이번 실습에서는 40 × 40 mm 크기의 케이블 덕트를 사용합니다. 실제 케이블 덕트는 슬롯과 커버 등 보다 복잡한 형상을 가지고 있지만 이번 프로젝트의 목적은 기초 모델링 연습이므로 단순한 직육면체 형태로 표현합니다. 이제 기성품을 고정할 판넬을 직접 설계합니다.

발표자 노트 · 원문 #### PLC 판넬 설계 이번 판넬에는 철판을 사용합니다. 두께는 2 mm로 설정합니다. 판넬 크기는 현재 배치된 기성품을 측정하여 결정합니다. 설계에서 중요한 것은 처음부터 임의의 치수를 정하는 것이 아니라 실제 사용할 부품의 크기를 확인하고 필요한 여유 공간을 계산하여 전체 크기를 결정하는 것입니다.

발표자 노트 · 원문 #### 측정 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-020.png) Fusion의 측정 기능을 이용하면 이미 배치된 부품 사이의 거리를 확인할 수 있습니다. 검사 → 측정 모터 한쪽 끝과 볼스크류 반대쪽 끝을 선택하여 전체 길이를 측정합니다. 이번 프로젝트에서는 약 581.20 mm가 측정되었습니다. 따라서 여유를 두어 가로 길이를 600 mm로 설정합니다. 세로 방향도 같은 방식으로 계산합니다. 모터 드라이브와 볼스크류의 크기, 그리고 케이블 덕트가 들어갈 공간을 고려하여 약 340 mm로 결정합니다. 최종 판넬의 크기는 다음과 같습니다. - 재료 : 철판 - 두께 : 2 mm - 가로 : 600 mm - 세로 : 340 mm

발표자 노트 · 원문 #### SERVO_PLATE 생성 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-021.png) 판넬을 직접 만들기 위해 새로운 구성요소를 생성합니다. 이름은 다음과 같이 지정합니다. `SERVO_PLATE` 구성요소를 생성했다면 반드시 SERVO_PLATE가 활성화되어 있는지 확인합니다. 스케치와 본체를 만드는 작업은 해당 구성요소가 활성화된 상태에서 진행해야 합니다.

발표자 노트 · 원문 #### 판넬 스케치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-022.png) 600 × 340 mm 크기의 직사각형을 그립니다. 이번에는 스케치를 원점 중심에 배치하기 위해 중심선과 각 끝단 사이의 거리를 지정합니다. - 가로 중심 : 300 mm - 세로 중심 : 170 mm Fusion에서는 치수에 직접 숫자를 입력하는 것뿐만 아니라 기존 치수를 이용한 수식도 사용할 수 있습니다. 예를 들어 전체 가로 치수의 절반을 사용하고 싶다면 기존 치수를 참조하여 `/2`와 같은 수식을 사용할 수 있습니다. 이렇게 만들어진 스케치를 완료합니다.

발표자 노트 · 원문 #### 판넬 돌출 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-023.png) 완성한 스케치를 2 mm 돌출합니다. 그 결과 다음 크기의 판넬이 만들어집니다. 600 × 340 × 2 mm 이제 기성품을 고정할 기본 판넬이 완성되었습니다.

발표자 노트 · 원문 #### 색상 적용 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-024.png) 여러 부품의 색상이 비슷하면 서로 구분하기 어려울 수 있습니다. Fusion의 색상 기능을 사용하여 부품마다 다른 색을 적용하면 작업하기 편리합니다. 수정 → 색상 색상 자체는 실제 재질과 반드시 동일하게 설정할 필요는 없습니다. 이번 과정에서는 각 구성요소를 쉽게 구분하는 것이 목적입니다.

발표자 노트 · 원문 #### 판넬에 PLC 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-025.png) 이제 PLC Set을 SERVO_PLATE에 배치합니다. 먼저 정렬 기능을 이용하여 PLC와 판넬의 면을 맞춥니다. 수정 → 정렬 접합과 달리 정렬에서는 기준점보다 면 자체를 선택합니다. 하나의 정렬만으로 모든 방향을 맞출 수 없는 경우에는 여러 번 정렬하여 각각의 면을 맞춥니다. 예를 들어 다음과 같은 순서로 진행할 수 있습니다. 1. 좌우 방향 정렬 2. 앞뒤 방향 정렬 3. 높이 방향 정렬 이렇게 하면 PLC가 판넬의 기준 위치에 배치됩니다.

발표자 노트 · 원문 #### 케이블 덕트 공간 확보 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-026.png) PLC를 판넬 끝에 바로 붙여 놓으면 케이블을 정리할 공간이 부족할 수 있습니다. 따라서 이동 기능을 사용하여 PLC 위치를 안쪽으로 이동시킵니다. 이번 실습에서는 케이블 덕트의 크기를 고려하여 약간의 여유 공간을 둡니다. 수치는 반드시 동일할 필요는 없습니다. 중요한 것은 케이블 덕트가 들어갈 수 있는 충분한 공간을 확보하는 것입니다.

발표자 노트 · 원문 #### 현재 위치에서 접합 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-027.png) 정렬과 이동만 사용한 부품은 위치만 변경된 상태이며 판넬과 실제 조립 관계가 설정된 것은 아닙니다. 이 상태에서 부품을 고정하기 위해 현재 위치에서 접합 기능을 사용합니다. 조립 → 현재 위치에서 접합 현재 위치에서 접합은 이미 원하는 위치에 배치한 두 구성요소를 움직이지 않고 현재 위치 그대로 서로 연결할 때 유용합니다. PLC Set과 SERVO_PLATE를 선택하여 고정합니다.

발표자 노트 · 원문 #### 모터 드라이브 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-028.png) 모터 드라이브도 동일한 방법으로 배치합니다. 1. 정렬 2. 이동 3. 주변 공간 확인 4. 현재 위치에서 접합 모터 드라이브 주변에도 케이블 덕트가 들어갈 공간을 확보해야 합니다. 특히 위쪽과 아래쪽으로 케이블이 연결될 수 있으므로 적절한 공간을 남겨 둡니다.

발표자 노트 · 원문 #### 서보모터와 볼스크류 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-029.png) 서보모터와 볼스크류 역시 같은 방식으로 SERVO_PLATE 위에 위치시킵니다. 정렬 기능으로 기준 위치에 배치한 뒤 필요한 만큼 이동하고, 최종 위치가 결정되면 현재 위치에서 접합하여 고정합니다. 이제 주요 기성품의 배치가 완료되었습니다.

발표자 노트 · 원문 #### 케이블 덕트 모델링 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-030.png) 이번에는 케이블 덕트를 직접 모델링합니다. 실제 케이블 덕트를 그대로 모델링하면 스케치가 상당히 복잡해지므로 이번에는 단순한 형태로 제작합니다. 새 구성요소를 만들고 다음과 같이 이름을 지정합니다. `CABLE_DUCT 40x40x600` 스케치에서 40 × 40 mm 사각형을 만든 뒤 600 mm 돌출합니다. 이렇게 하면 판넬 가로 방향에 사용할 간단한 케이블 덕트가 완성됩니다.

발표자 노트 · 원문 #### 케이블 덕트 배치 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-031.png) 만든 케이블 덕트를 SERVO_PLATE 끝부분에 정렬합니다. 위치가 결정되면 현재 위치에서 접합을 이용하여 판넬과 고정합니다. 필요하면 색상을 변경하여 다른 부품과 쉽게 구분할 수 있도록 합니다.

발표자 노트 · 원문 #### 케이블 덕트 복사 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-032.png) 동일한 크기의 케이블 덕트를 다시 만들 필요는 없습니다. 이동/복사 기능을 사용하면 기존 구성요소를 복사할 수 있습니다. 수정 → 이동/복사 이때 다음 두 가지를 확인합니다. - 사본 작성 선택 - 이동 객체를 구성요소로 지정 복사된 덕트를 원하는 위치로 이동시킨 뒤 현재 위치에서 접합하여 고정합니다.

발표자 노트 · 원문 #### 세로 케이블 덕트 제작 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-033.png) 가로 덕트 사이의 공간을 측정하여 세로 방향으로 사용할 케이블 덕트의 길이를 결정합니다. 이번 프로젝트에서는 약 190 mm 공간을 기준으로 다음 크기의 덕트를 제작합니다. 40 × 40 × 190 mm 새 구성요소를 생성하고 40 × 40 mm 스케치를 만든 뒤 190 mm 돌출합니다. 완성된 덕트 역시 정렬과 현재 위치에서 접합을 사용하여 SERVO_PLATE에 고정합니다. 필요한 경우 이동/복사 기능으로 동일한 부품을 추가합니다.

발표자 노트 · 원문 #### 프로젝트 완성 이 과정을 통해 처음으로 여러 기성품과 직접 모델링한 부품을 조합하여 하나의 장비 형태를 완성했습니다. 이번 프로젝트에서 사용한 핵심 기능은 다음과 같습니다. - 외부 STEP 파일 불러오기 - 구성요소 관리 - 강체 그룹 - 상위로부터 고정 및 해제 - 접합 - 이동 - 정렬 - 현재 위치에서 접합 - 측정 - 스케치 - 돌출 - 이동/복사 - 색상 변경 새로운 고급 기능을 사용한 것은 많지 않습니다. 기본 기능을 반복해서 사용했을 뿐이지만 실제 장비와 비슷한 형태의 모델을 만들 수 있었습니다.

발표자 노트 · 원문 #### 아직 남아 있는 문제 현재 모델은 기본적인 구조만 완성한 상태입니다. 실제 제작을 위해서는 아직 해결해야 할 부분이 있습니다. 1. PLC, 모터 드라이브, 볼스크류, 케이블 덕트를 실제로 고정할 구조가 없다. 2. 실제 제작 시에는 Hole과 Tap 등을 추가하고 볼트를 이용한 체결 구조를 설계해야 한다. 3. 현재의 얇은 철판은 크기에 따라 휨이 발생할 수 있으므로 절곡 등을 이용한 보강을 고려해야 한다. 4. 케이블 덕트는 실제 형상을 단순화하여 모델링했다. 5. 실제 케이블이 지나갈 공간과 굽힘 반경 등을 추가로 고려해야 한다. 이러한 부분은 이후 다른 프로젝트를 진행하면서 하나씩 개선해 나갑니다.

발표자 노트 · 원문 #### 이번 프로젝트에서 배운 설계의 핵심 이번 프로젝트에서 가장 중요하게 확인한 것은 Fusion의 특정 명령어가 아닙니다. 실제 기계 설계가 어떤 방식으로 이루어지는지를 이해하는 것이 더 중요합니다. > 우리가 직접 만드는 부품은 생각보다 많지 않습니다. > > > 대부분 필요한 기성품을 선정하고 배치한 뒤, > > 기성품을 연결하고 사용할 수 있도록 필요한 구조물을 설계합니다. > 즉, 실제 설계의 흐름은 다음과 같이 생각할 수 있습니다. 요구사항 확인 ↓ 기성품 검색 ↓ 기성품 선정 ↓ CAD 데이터 확보 ↓ 3D 공간에 배치 ↓ 필요한 구조물 설계 ↓ 조립 및 간섭 검토 ↓ 제작 이것이 이번 프로젝트에서 익혀야 할 가장 중요한 설계 흐름입니다.

발표자 노트 · 원문 #### 반복 연습 앞으로 진행하게 될 컨베이어, 자동차, 로봇 등의 프로젝트에서는 이번 프로젝트처럼 모든 과정을 하나씩 자세하게 설명하지 않습니다. 이번 프로젝트에서 사용한 기본적인 작업 방법을 알고 있다는 것을 전제로 진행합니다. 따라서 다음 기능은 충분히 익숙해질 때까지 반복해서 사용해 보는 것이 좋습니다. - 구성요소 생성 - STEP 파일 삽입 - 이동 - 정렬 - 접합 - 현재 위치에서 접합 - 스케치 - 돌출 - 측정 - 복사 3D 모델링은 단순히 지식을 이해하는 것보다 직접 반복하면서 손에 익히는 것이 중요합니다. 이번 프로젝트가 어렵게 느껴진다면 같은 과정을 한 번 더 처음부터 반복해 보는 것도 좋은 연습이 됩니다. 설계는 한 번에 완벽하게 만드는 작업이 아닙니다. 부품을 배치하고, 수정하고, 다시 배치하고, 필요한 구조를 추가하는 과정을 반복하면서 점차 완성해 나가는 작업입니다. ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-034.png) 40 x 40 사각형을 스케치한 뒤, [작성] → [돌출] 을 이용해 600mm 돌출한다. ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-035.png) 이제 CABLE_DUCT 를 위치시키기 위해 브라우저에서 ServoKit 의 구성요소를 활성화한다. 만약 아직 저장하지 않아 [저장되지 않음] 으로 되어 있다면 ServoKit 으로 저장을 해도 되고, 아니면 다른 적당한 이름을 사용해도 좋다. ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-036.png) 그 다음 [수정] → [정렬] 기능을 사용해 CABLE_DUCT 40x40x600 을 SERVO_PLATE 끝에 위치시키고, [조립] → [현재 위치에서 접합] 으로 고정한다. ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-038.png) 이번에는 [수정] → [이동/복사] 기능을 이용해 CABLE_DUCT 40x40x600 을 복사한다. 이때 [사본 작성] 에 체크해야 복사가 되며, 객체 이동 대상은 반드시 [구성요소]로 지정해야 한다. 필자의 경우 복사 위치는 ![image.png](../assets/02-03-servo-motor-kit-modeling/asset-046.png) 이렇게 해서 우리가 처음으로 하나의 프로젝트를 완성해 보았다. **아직 남아 있는 문제** 1. PLC, 모터 드라이브, 볼스크류, 케이블 덕트 등을 고정할 구조가 없다. 실제로는 TAP이나 HOLE을 추가하고, 볼트 등을 사용해 고정 구조를 만들어야 한다. 2. 철판 Plate 를 이 상태로 사용하면 휨이 발생할 가능성이 높다. 따라서 바닥 부분을 약간 접어 보강할 필요가 있다. 3. 케이블 덕트를 실제 형태에 가깝게 모델링하지 않았다. 아직 부족한 부분은 많지만, 이번 프로젝트는 여기까지로 마무리하겠다. 이후 다른 프로젝트를 통해 조금 더 연습해 보고, CABLE_DUCT와 SERVO_PLATE는 다른 방식으로 다시 만들어 볼 예정이다. **이번 프로젝트를 통해 확인할 수 있었던 점** 이번 프로젝트를 통해 다시 한번 확인할 수 있었던 것은 다음과 같다. > 우리가 직접 만드는 것은 많지 않다. 대부분은 기성품을 찾고 배치한 뒤, 그것들을 서로 연결하여 사용할 수 있도록 구조물을 만들고 조립하는 일이다. > 이후에 만들게 될 컨베이어, 자동차, 로봇, 그리고 다시 새롭게 그릴 서보모터 키트는 이번 프로젝트처럼 하나하나 자세한 설명 없이 진행될 예정이다. 따라서 이번 프로젝트의 내용을 충분히 익혀 두는 것이 중요하다. 또한 이 과정은 단순한 지식이 아니라 기술에 가깝다. 기술을 익히는 가장 좋은 방법은 반복을 통해 익숙해지는 것이다. 그렇기 때문에 이 프로젝트를 다시 한번 반복해 보는 것 자체가 매우 좋은 연습이 될 것이다.
