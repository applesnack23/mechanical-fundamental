# 탭 작업 시 주의 사항

- 탭을 가공면에 최대한 수직으로 유지합니다.
- 무리하게 힘을 가하지 않습니다.
- 금속 가공에서는 탭핑유 또는 절삭유를 사용합니다.
- 절삭칩이 쌓이지 않도록 관리합니다.

# 공구 선택의 기본 원칙

- PH1, PH2 십자 드라이버
- 소형 일자 드라이버
- 정밀 드라이버 세트
- 1.5~6 mm 정도의 육각렌치 세트
