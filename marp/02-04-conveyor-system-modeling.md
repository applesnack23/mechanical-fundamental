- STL : 3D 프린팅용 데이터로 많이 사용하는 형식
- IGES : CAD 데이터 교환용 형식

# 타이밍 벨트와 풀리

![bg right:44% contain](../assets/02-04-conveyor-system-modeling/asset-005.png)

- 모터의 회전력을 샤프트로 전달하기 위해 타이밍 벨트와 타이밍 풀리를 사용합니다.
- 일반적인 매끄러운 벨트와 풀리는 큰 힘이 전달될 때 미끄러질 수 있습니다.
- 타이밍 벨트와 풀리에는 서로 맞물리는 톱니가 있기 때문에 회전력을 보다 정확하게 전달할 수 있습니다.

# 풀리비와 회전 속도

![bg right:44% contain](../assets/02-04-conveyor-system-modeling/asset-028.png)

- 모터 풀리가 한 바퀴 회전하면 타이밍 벨트는 30개의 톱니만큼 이동합니다.
- 샤프트 풀리의 톱니 수는 20개이므로 같은 벨트 이동량에 대해 샤프트 풀리는 더 많이 회전하게 됩니다.
- 회전비는 다음과 같이 생각할 수 있습니다.

<!--
발표자 노트 · 원문
